# Quantum Neural Network for Credit Card Fraud Detection

## Overview
Comparing classical Machine Learning vs Quantum Neural Network performance 
for detecting credit card fraud using real world transaction data.

## Problem
Only 492 fraud cases out of 284,807 transactions (0.17%).
Classical models miss critical fraud cases.
Can Quantum Neural Networks do better?

## Tech Stack
- Python
- PennyLane (Quantum Computing)
- Scikit-learn (Classical ML)
- Pandas & NumPy (Data Processing)
- Matplotlib & Seaborn (Visualization)
